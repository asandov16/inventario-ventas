# ADR-001 — Framework de interfaz: React + TypeScript + Vite

- **Estado:** Aceptada
- **Fecha:** 2026-11-03
- **Origen:** D-01

## Contexto

La app es una PWA estática sin servidor propio. Se evaluaron React y Svelte.

## Decisión

React 19 + TypeScript (strict) + Vite, como SPA estática.

## Consecuencias

Ecosistema amplio y facilidad para conseguir ayuda. Cambiar después tiene costo alto.
