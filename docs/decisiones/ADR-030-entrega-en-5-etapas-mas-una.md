# ADR-030 — Entrega en 5 etapas más una posterior

- **Estado:** Aceptada
- **Fecha:** 2026-11-03
- **Origen:** Plan §2

## Contexto

El roadmap tiene 11 fases; se pidió no construir todo de una vez ni tener demasiadas fases.

## Decisión

Etapas: 0 Fundaciones (F0), 1 Núcleo de datos (F1+F2), 2 App y Vender (F3+F4), 3 Operación diaria (F6+F5+F7), 4 Producción y beta (F8+F9), 5 Sin conexión (F10). Cada etapa termina con una revisión.

## Consecuencias

Aclaración: el modelo tiene 19 tablas (vale el roadmap sobre las 17 de Req. Técnicos).
